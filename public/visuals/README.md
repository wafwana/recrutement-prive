# Visuels du site

La page publique utilise quatre assets locaux dans ce dossier :

- `hero-portrait.jpeg` — portrait principal de l'accueil.
- `cabinet-office.jpeg` — photo du cabinet.
- `enterprise-handshake.jpeg` — visuel entreprises.
- `ai-human.jpeg` — visuel technologie / IA.

Les fichiers doivent être de vraies images JPEG/WEBP livrables dans `public/visuals/`. Aucun chemin `/mnt/data/...`, URL externe ou fichier texte déguisé en image ne doit être utilisé par la page.

La référence visuelle de la maquette est conservée séparément uniquement pour le travail de conception.
